# **Better Survival Blueprint Tool**

[[English]](README.md)|[中文]

## **一、介绍**
本模组为[Sable Photomancy](https://github.com/Rew1nd-dev/sable-schematic-api)的附属模组添加了一个蓝图工具*blueprint tool*，不同 于原版的蓝图工具蜂蜜焊枪，它只有两个板块：无碰撞和焊接，且焊接不会消耗燃料，同时满足了玩家在生存模式也想使用无碰撞功能的需求。

## **二、须知**
本模组所需Minecraft1.21.1，NeoForge版本使用21.1.238及以上版本，使用MIT协议
